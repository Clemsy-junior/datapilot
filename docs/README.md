## `demo.gif` — à enregistrer

Le README référence `docs/demo.gif`. Enregistrez-le vous-même : c'est la
première chose que regarde un recruteur, et une capture de votre propre écran
vaut mieux qu'une image générée.

Scénario suggéré, environ 20 secondes :

1. `make up`, puis ouvrir <http://localhost:8080>.
2. Cliquer « Quelle région performe le mieux ? ».
3. Laisser voir la trace se remplir en direct : `list_columns`, puis
   `aggregate`, puis `make_chart`, avec les durées.
4. Déplier « Résultat brut » sur l'appel `aggregate` — c'est le moment qui
   montre que les chiffres de la réponse viennent bien de là.
5. Laisser le graphique s'afficher.

Outils possibles : [asciinema](https://asciinema.org/) (terminal),
[peek](https://github.com/phw/peek) ou [LICEcap](https://www.cockos.com/licecap/)
(écran). Visez moins de 5 Mo pour que GitHub l'affiche sans traîner.
